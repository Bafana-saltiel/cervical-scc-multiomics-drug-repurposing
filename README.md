# Cervical SCC Multi-Omics and Drug Repurposing

Reproducible R workflows for multi-omics characterization of cervical squamous cell carcinoma (SCC), proteomic keratinization-state classification, biomarker discovery, and state-guided drug repurposing.

## Study workflow

```text
TCGA-CESC
   │
   ├── RPPA proteomics
   ├── RNA expression
   ├── DNA methylation
   └── Somatic mutation (MAF)
          │
          ▼
Data preprocessing and cohort harmonisation
          │
          ▼
Multi-omics feature discovery
          │
          ▼
SCC-K vs SCC-NK classifier development
          │
          ▼
Five-protein RPPA classifier
ZAP-70 · EVI1 · EPPK1 · ANNEXIN1 · CD171
          │
          ▼
SCC-NOS molecular-state resolution
          │
          ▼
Keratinizing-state RNA signature
          │
          ▼
L1000 perturbational-signature reversal
          │
          ▼
Candidate compounds
          │
          ▼
Pharmacological follow-up
```

## First-stage preprocessing

Run the scripts in numerical order:

```r
source("01_data_preprocessing/01_RPPA_preprocessing.R")
source("01_data_preprocessing/02_RNA_preprocessing.R")
source("01_data_preprocessing/03_methylation_preprocessing.R")
source("01_data_preprocessing/04_MAF_preprocessing.R")
source("01_data_preprocessing/05_multiomics_cohort_harmonisation.R")
```

The scripts expect source files under `data/raw/` by default. File locations can
also be supplied through environment variables:

- `CESC_RPPA_FILE`
- `CESC_RNA_FILE`
- `CESC_METHYLATION_FILE`
- `CESC_MAF_FILE`

Example:

```r
Sys.setenv(CESC_RPPA_FILE = "/path/to/rppa_file.tsv")
```

## Reproducibility principles

- Raw TCGA/GDC, DepMap, GDSC, L1000, and other externally distributed datasets
  should not be committed unless their redistribution terms permit it.
- Record the original accession, download date, source URL, and version for
  every external dataset in the eventual data manifest.
- Processed objects generated by the scripts are written to `data/processed/`.
- Downstream diagnosis/state filtering is intentionally separated from the
  initial multi-omics cohort harmonisation step.
- The repository is intended to preserve analysis provenance rather than
  redistribute third-party source data.

## Scientific scope

The downstream study uses RPPA measurements to resolve molecular variation
associated with cervical SCC keratinization states. The final classifier uses
five RPPA features: ZAP-70, EVI1, EPPK1, ANNEXIN1, and CD171.

The classifier is subsequently used to resolve SCC-NOS tumours along a
keratinization axis. The RNA programme associated with the proteomically
defined keratinizing state is then used as the input for L1000
perturbational-signature matching.

L1000 candidates are computational hypotheses for experimental testing; their
identification does not establish drug sensitivity or clinical efficacy.
